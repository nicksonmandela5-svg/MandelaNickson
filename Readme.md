C++ OOP Take-Home Assignment

Chained Inheritance and Polymorphism

1. Introduction

This project demonstrates multilevel inheritance and runtime polymorphism in C++ using real-world examples.

2. Objectives

- To demonstrate inheritance and code reuse.
- To implement polymorphism using virtual functions.
- To understand function overriding in derived classes.

3. Programs

Chained Inheritance: Uses three classes: "Person", "Student", and "UniversityStudent". Each class inherits accessible members from its parent class.

Polymorphism: Uses "Payment", "CashPayment", and "MobileMoneyPayment" to demonstrate how the same virtual function produces different behaviours.

4. Requirements

- C++ compiler (GCC or MinGW).
- Code editor.
- Hand-drawn diagrams illustrating both concepts.

5. Compilation and Execution

Compile and run the inheritance program:

g++ inheritance.cpp -o inheritance
./inheritance

Compile and run the polymorphism program:

g++ polymorphism.cpp -o polymorphism
./polymorphism

6. Illustrations

Photographs of the hand-drawn inheritance and polymorphism diagrams should be saved in the "illustrations" folder.

7. Conclusion

The project demonstrates how inheritance promotes code reuse and polymorphism enables different behaviours through a common interface.
